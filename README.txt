NIVYESH CHAUDHARI — PYTHON PORTFOLIO

1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Run:
   pip install -r requirements.txt
4. Start:
   python app.py
5. Open:
   http://127.0.0.1:5000

PROFILE IMAGE:
Edit the profile <img src="..."> URL in templates/index.html.

LINKEDIN/GITHUB:
Add your real URLs in the contact section of templates/index.html.

RESUME:
Copy your PDF resume into this folder as:
Nivyesh_Resume_DA(1).pdf
Then add a Flask /resume route if you want the button to serve it.
